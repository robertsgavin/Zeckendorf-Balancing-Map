# Zeckendorf-Balancing-Map
Fixed points of a balancing map on generalized Zeckendorf representations (Fibonacci, Tribonacci, Padovan, Pell, Tetranacci, and more) — proved asymptotic ratios α/(α−1) and 1/(α−1) depending on the recurrence's dominant root α, with a genuine two-family dichotomy when α > 2. Verified via exact integer arithmetic up to n = 20,000.
